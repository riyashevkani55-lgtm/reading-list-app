# Reading List App

A simple, responsive web application that helps students organize their books and track their reading progress.

## Features

- **Add Books:** Add books to your reading list by entering their titles.
- **Reading Status:** Set each book's status to Want to Read, Reading, or Finished.
- **Filter Books:** Filter the list according to reading status.
- **Duplicate Prevention:** Prevent duplicate book titles, ignoring uppercase/lowercase differences and extra spaces.
- **Title Validation:** Limit book titles to a maximum of 60 characters.
- **Delete Books:** Remove individual books from the reading list.
- **Summary Dashboard:** Display the total number of books, books currently being read, and finished books.
- **Responsive Design:** Use the application on desktop and mobile-sized screens.

## Technologies

- React
- TypeScript
- CSS
- Vite

## How to Use

1. Open the application.
2. Enter a book title.
3. Select its reading status.
4. Click **Add to List**.
5. Change statuses, filter books, or delete books as needed.
6. Check the summary cards to track your reading progress.

## Data Storage

The application keeps its reading-list data in the browser. It does not require an account or a cloud database.

## Deployment

The application is deployed using Vercel.
